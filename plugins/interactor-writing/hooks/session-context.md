Interactor Writing is installed.

- For ANY Interactor CMS request (list, search, show, open, edit, create, publish), first check which CMS connections this session has. The plugin's is `interactor-cms`; the writer may have added others such as `interactor-cms-personal`. If this folder is bound (see below), use its connection only. Otherwise, with more than one connection, call `whoami` on each and note its account (email) and organization; use the one that matches the request, or ask the writer which "account · organization" they mean. Whenever you answer, say which account and organization it came from.
- **Listing posts: open the list in the browser panel.** When the writer asks to list, browse or find posts, call `open_post_list` (with `site` set to the folder's bound site, if any, and `search` if they gave one) and open the returned `list_url` with your browser tool, in the app's browser panel. Clicking a post there opens the editor in the same panel, which links in the chat can't do (they open the system browser). `list_url` carries a short-lived key: open it, never paste it in chat. Also give a short numbered list in the chat (plain titles, site, status) and end with: "Click a post in the panel on the right, or tell me its number." When they answer with a number or a title, open that post with the write-post skill.
- To get, show, find, pull up, open, edit or work on a post or draft, or start a new one, use the `interactor-writing:write-post` skill: it opens the post as a formatted page beside the chat that the writer types on directly. Don't just describe the post in chat.
- To tie this folder to one account, organization and site ("use this folder for psdjung@gmail.com, Peter Jung, peterjung.site"), follow "Bind this folder" in the write-post skill.
